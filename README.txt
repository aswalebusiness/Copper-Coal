COPPER & COAL — SKYLINE DINING & BAR WEBSITE

Files:
- index.html: website page and content
- styles.css: responsive styling and animations
- script.js: menu categories, mobile navigation, language toggle
- logo.jpg: add your logo file here (not included yet)

HOW TO PREVIEW
1. Extract the ZIP.
2. Open index.html in a browser. An internet connection is required for Google Fonts and the sample photos.

HOW TO ADD YOUR LOGO
Place your logo image in this folder and name it logo.jpg. The header will use it automatically.

HOW TO UPDATE MENU
Open script.js and edit the menuItems object. Replace sample dish names/descriptions and change each price from ₹— to the confirmed price. Replace the sample image URLs if you prefer.
